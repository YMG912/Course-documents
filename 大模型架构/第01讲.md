### Loss Functions Turn Learning into Optimization

- Loss L(ŷ, y): a number scoring how wrong ONE prediction is. Zero = perfect.

- Empirical risk: the average loss over the training set — one number for the whole model.

- ERM principle: pick the parameters that minimize that average.

- Why this matters: “learning” is now a concrete math problem — minimize a function. Calculus takes over from here.

“the best parameters are the ones with the smallest average loss”

The two losses of this course

Regression L = (ŷ − y)² squared distance to the target Classification L = −log p(true class) “surprise” at the correct answer

Both derived carefully in Hour 2. The second one trains GPT — literally the same formula, at trillion scale.

θ* = argmin_θ (1/N) Σ L( f(x(i);θ), y(i) )

### Mean Squared Error

price (M¥)

area (m²)

one candidate line — dashed = residuals ŷ(i) − y(i)

L(w,b) = (1/N) Σ ( w·x(i)+b − y(i) )² average squared miss, over all N examples

- Residual: each dashed segment — one prediction’s miss.

- Why square it? kills the sign (+2 and −2 are equally bad), punishes big misses hard, and is smooth — differentiable everywhere.

- Key mental shift: L is a function of w and b, not of x. The data is fixed; the knobs move.

- For one w (b fixed), L(w) is a parabola — a bowl with a single bottom.

### Minimizing the Loss: Two Roads

ROAD 1

Solve it exactly

- Set ∇L = 0, solve for (w, b) in closed form — the “normal equation”.

- Beautiful. Instant. No iterations.

- But it only exists for a handful of simple models. Add any nonlinearity — or a billion parameters — and the algebra dies.

ROAD 2

Walk downhill, step by step

- Start anywhere. Repeatedly take a small step in the direction that lowers L.

- Works for ANY differentiable loss — lines, MLPs, CNNs, Transformers, GPT.

- This is the road for the rest of the course — and the rest of the field.

Deep learning in one sentence: give up on exact answers, get a method that works for everything.

### Gradient Descent: Downhill in the Fog

### Fifteen Lines That Learn

The live example predicts apartment price (million yuan) from area (square metres). It follows **forward → loss → gradient → update**.

```python
import numpy as np

x = np.array([50, 80, 100, 120, 60])  # area (m²)
y = np.array([3.0, 5.1, 6.0, 7.4, 3.8])  # price (million yuan)
w, b, lr = 0.0, 0.0, 0.0001

for step in range(2000):
    y_hat = w * x + b             # 1. forward
    err = y_hat - y               # residual
    loss = (err**2).mean()        # 2. mean squared error
    dw = 2 * (err * x).mean()     # 3. ∂L/∂w
    db = 2 * err.mean()           #    ∂L/∂b
    w -= lr * dw                  # 4. update
    b -= lr * db

print(w, b)  # approximately 0.0605, -0.05
```

The derivative $\partial L/\partial w=2\operatorname{mean}(\mathrm{err}\cdot x)$ follows from the chain rule. Later lessons replace the model and gradient computation while retaining the same loop.

### Cross-Entropy: The Price of Surprise

For $y\in\{0,1\}$ and predicted probability $p$, binary cross-entropy is

$$L=-[y\log p+(1-y)\log(1-p)]=-\log p(\text{true class}).$$

Interpret it as the *surprise* assigned to the correct answer:

| Probability given to true class | Loss $-\log p$ | Verdict |
| ---: | ---: | --- |
| 0.99 | 0.01 | Confident and right |
| 0.90 | 0.11 | Good |
| 0.50 | 0.69 | Uncertain |
| 0.10 | 2.30 | Wrong |
| 0.01 | 4.61 | Confidently wrong |

Here `log` is the natural logarithm; losses are measured in nats. Minimizing cross-entropy is maximum likelihood for Bernoulli labels. The multiclass softmax version is GPT's actual training loss.

### Both Losses Are Maximum Likelihood

GAUSSIAN

Regression → MSE

- Assume Gaussian noise: y = f(x;θ) + ε, ε ~ N(0, σ²).

- −log p(y|x) = (y − f(x;θ))² / 2σ² + const — so max likelihood = min MSE, exactly.

- The square is not a design choice — it is the exponent of the Gaussian density.

BERNOULLI

Classification → CE

- The model outputs a Bernoulli: p = σ(w·x + b), so p(y|x) = p^y · (1−p)^(1−y).

- −log p(y|x) = −[ y·log p + (1−y)·log(1−p) ] — cross-entropy, word for word.

- Minimizing CE = maximizing the probability of the labels — now proved.

One principle, two noise models — GPT’s next-token loss is the categorical case.

### Gaussian Likelihood Derivation, Part 1

#### 0. Write the Gaussian density

For a Gaussian distribution $\mathcal N(\mu,\sigma^2)$,

$$p(y)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y-\mu)^2}{2\sigma^2}\right).$$

Assume $y=f(x;\theta)+\epsilon$ with zero-mean noise $\epsilon\sim\mathcal N(0,\sigma^2)$. Then $y$ is Gaussian around $f(x;\theta)$:

$$p(y\mid x;\theta)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y-f(x;\theta))^2}{2\sigma^2}\right).$$

The parameter $\theta$ appears only inside $f(x;\theta)$, not in the Gaussian normalization factor.

#### 1. Multiply independent sample densities

For $n$ independent examples, $L(\theta)=\prod_{i=1}^{n}p(y_i\mid x_i;\theta)$.

#### 2. Take a logarithm

The logarithm is strictly increasing, so it does not change the maximizing $\theta$. It turns products into sums and removes the exponential:

$$\log L(\theta)=\sum_i\left[-\frac{(y_i-f(x_i;\theta))^2}{2\sigma^2}-\frac12\log(2\pi\sigma^2)\right].$$

### Gaussian Likelihood Derivation, Part 2

#### 3. Remove terms independent of $\theta$

The term $-\tfrac12\log(2\pi\sigma^2)$ and the positive factor $1/(2\sigma^2)$ do not change where the maximum occurs. Therefore

$$\operatorname*{argmax}_{\theta}\log L(\theta)
=\operatorname*{argmax}_{\theta}\left[-\sum_i(y_i-f(x_i;\theta))^2\right]
=\operatorname*{argmin}_{\theta}\sum_i(y_i-f(x_i;\theta))^2.$$

Multiplying by $1/n$ also preserves the minimizer. Thus Gaussian maximum likelihood is equivalent to minimizing mean squared error (MSE).

### Bernoulli Likelihood Derivation, Part 1

#### 0. Write the Bernoulli distribution

For binary classification, $p=\sigma(w\cdot x+b)=P(y=1\mid x)$, so $P(y=0\mid x)=1-p$. Both cases are expressed by

$$P(y\mid x)=p^y(1-p)^{1-y},\qquad y\in\{0,1\}.$$

For $y=1$ this becomes $p$; for $y=0$ it becomes $1-p$. The parameters $w,b$ enter through $p$.

#### 1. Multiply independent sample probabilities

$$L(\theta)=\prod_i p_i^{y_i}(1-p_i)^{1-y_i},\qquad p_i=\sigma(w\cdot x_i+b).$$

#### 2. Take a logarithm

Using $\log(ab)=\log a+\log b$ and $\log(a^b)=b\log a$,

$$\log L(\theta)=\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].$$

### Bernoulli Likelihood Derivation, Part 2

#### 3. Negate and average

To minimize a loss instead of maximizing likelihood, take the negative mean:

$$L_{\mathrm{CE}}(\theta)=-\frac1n\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].$$

This is binary cross-entropy, derived directly from the Bernoulli likelihood. Unlike the Gaussian derivation, there is no normalization constant to discard.

### Why Not MSE for Classification? Follow the Gradient

Cross-entropy loss MSE (after sigmoid)

- Very wrong (z ≪ 0): CE keeps a steady slope → strong gradient → fast fix.

- MSE plateaus there: gradient carries σ′(z), which → 0 at the extremes. Confidently- wrong model… barely learns.

- Bonus: MSE + sigmoid is non-convex; CE + sigmoid is convex. One clean bowl.

“The wronger you are, the harder the loss should push back.” CE obeys this law. MSE breaks it.

### Sigmoid and Cross-Entropy Gradient Derivation

Let $z=w^\top x+b$, $p=\sigma(z)=1/(1+e^{-z})$, and $y\in\{0,1\}$.

#### 1. Differentiate sigmoid

$$\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}
=\frac{1}{1+e^{-z}}\frac{e^{-z}}{1+e^{-z}}
=p(1-p).$$

#### 2. Differentiate cross-entropy

For one example, $L_{\mathrm{CE}}=-[y\log p+(1-y)\log(1-p)]$. First,

$$\frac{\partial L_{\mathrm{CE}}}{\partial p}
=-\left[\frac{y}{p}-\frac{1-y}{1-p}\right]
=\frac{p-y}{p(1-p)}.$$

The chain rule cancels the $p(1-p)$ factor:

$$\frac{\partial L_{\mathrm{CE}}}{\partial z}
=\frac{p-y}{p(1-p)}p(1-p)=p-y.$$

Going back through $z=w^\top x+b$ gives $\partial L_{\mathrm{CE}}/\partial w=(p-y)x$ and $\partial L_{\mathrm{CE}}/\partial b=p-y$. This cancellation is why the gradient remains strong even when a prediction is confidently wrong.

### MSE Gradient and Saturation

#### 3. Compare mean squared error after sigmoid

For one example, $L_{\mathrm{MSE}}=(p-y)^2$. Consequently,

$$\frac{\partial L_{\mathrm{MSE}}}{\partial p}=2(p-y),\qquad
\frac{\partial L_{\mathrm{MSE}}}{\partial z}=2(p-y)p(1-p),\qquad
\frac{\partial L_{\mathrm{MSE}}}{\partial w}=2(p-y)p(1-p)x.$$

The $p(1-p)$ factor remains. Its maximum is $1/4$; it decays approximately as $e^{-|z|}$ when $|z|$ grows. Thus MSE's logit gradient is $2p(1-p)$ times the cross-entropy logit gradient.

#### 4. Numerical comparison when $y=0$

| Logit $z$ | Probability $p$ | $\partial L_{\mathrm{CE}}/\partial z$ | $\partial L_{\mathrm{MSE}}/\partial z$ |
| ---: | ---: | ---: | ---: |
| 0 | 0.5 | 0.5 | 0.25 |
| 5 | 0.993 | 0.993 | 0.013 |
| 10 | 0.99995 | 0.99995 | $9\times10^{-5}$ |

As the confidently wrong prediction becomes more extreme, the cross-entropy gradient approaches 1 while the MSE gradient nearly vanishes.

### Convexity of Cross-Entropy and Nonconvexity of MSE

#### 5. Second derivatives and convexity

For cross-entropy,

$$\frac{\partial^2 L_{\mathrm{CE}}}{\partial z^2}
=\frac{\partial(p-y)}{\partial z}=p(1-p)>0.$$

Because $z=w^\top x+b$ is affine in $w$, the Hessian with respect to $w$ is $p(1-p)xx^\top\succeq0$: logistic cross-entropy is convex in the weights.

For MSE, let $q=p(1-p)$ and $q'=p(1-p)(1-2p)$. Then

$$\frac{\partial^2 L_{\mathrm{MSE}}}{\partial z^2}
=2[q^2+(p-y)q']
=2p(1-p)\left[p(1-p)+(p-y)(1-2p)\right].$$

At $y=0$ and $p=0.9$, the bracket is $0.09+0.9(-0.8)=-0.63<0$. The curvature changes sign, so MSE after sigmoid is nonconvex; confidently wrong regions can contain flat or concave parts.

### The Beautiful Gradient: (p − y) · x

For sigmoid plus binary cross-entropy,

$$\frac{\partial L}{\partial w}=(p-y)x.$$

- **$p-y$ is the error signal.** Correct and certain predictions give a value near 0; confidently wrong predictions give a value near $\pm1$.
- **$x$ assigns credit.** Features with larger values receive larger weight corrections because they contributed more to the score.
- The same pattern appears in linear regression, and softmax plus cross-entropy yields $(p-y)x$ again for multiclass classification. It is part of GPT's training computation.

### 1958: The Perceptron

The perceptron is an early trainable classifier. It computes a weighted sum of input features, applies a threshold, and changes its weights when it misclassifies a labeled example. Its historical hardware implementation showed that a machine could improve a simple pattern-recognition task through examples.

### The Perceptron Learning Rule

The algorithm (labels y = ±1)

- Loop through examples, one at a time

- Correctly classified → do nothing

- Mistake → w ← w + y·x , b ← b + y

- Repeat until no mistakes remain

Convergence theorem (Rosenblatt 1962): if the data IS linearly separable, this stops after finitely many mistakes.

after one update

before (missed the circled point)

each mistake rotates the boundary toward the point it missed

Label switch from the last slide: {0,1} → {±1}, so that correct ⇔y·(w·x + b) > 0 and one update w ← w + y·x covers both classes (with y = 0 it would no-op).

### Why the Rule Works: The Gradient View

Each update = one gradient step

- Loss per example: L = max(0, −y·(w·x + b))

- Correct → L = 0, gradient = 0 → do nothing

- Mistake → L = −y·(w·x + b), so ∂L/∂w = −y·x, ∂L/∂b = −y

- One step downhill → w ← w + y·x , b ← b + y — exactly the rule!

The recipe of modern deep learning: define a loss, then follow its gradient downhill.

### Perceptron vs. Logistic Regression

| Property | Perceptron (1958) | Logistic regression |
| --- | --- | --- |
| Output | Hard 0/1 label | Probability in $(0,1)$ |
| Activation | Step function | Smooth sigmoid |
| Differentiable? | No | Yes |
| Training | Mistake-driven update | Gradient descent on cross-entropy |
| Nonseparable data | Can loop forever | Finds a best tradeoff |
| Role today | Historical landmark | Common industry classifier |

Backpropagation uses chain-rule gradients through many layers, so differentiability matters. The perceptron's hard step supplies no useful gradient; smooth activations do.

### XOR: The Four Points No Line Can Split

XOR: 1 iff inputs differ

×

(0,0) (1,0)

every candidate line strands one point on the wrong side

- XOR: output 1 exactly when the two inputs differ. The orange pair sits on opposite corners.

- One line = two half-planes. But (0,1) and (1,0) must be grouped together AWAY from (0,0) and (1,1) — diagonals can’t be split by one cut.

- Proof in four inequalities: b < 0, w₂ + b > 0, w₁ + b > 0, w₁ + w₂ + b < 0. Add the middle two: w₁ + w₂ + 2b > 0 — contradiction.

- Not “hard to learn” — impossible. No algorithm can find a line that does not exist.

- The idea: don’t draw one line — draw two, then combine the regions.

- XOR = OR minus AND: “at least one input is on, but not both”.

- Layer 1 computes two familiar gates — each a single learnable line.

- Layer 2 is one more line — in the NEW space (h₁, h₂).

- The hidden layer invents new features. That is what “deep” buys.

### Lecture 1: Three Ideas to Keep

1. **Learning is optimization.** Choose a hypothesis space, loss, and empirical risk minimization strategy. The five-step recipe is data, model, loss, optimizer, evaluation, whether fitting a line or training GPT.
2. **Gradient descent needs the right loss.** Update $\theta\leftarrow\theta-\eta\nabla L$ on mini-batches. Use MSE for regression and cross-entropy for classification; the latter's $(p-y)x$ gradient remains strong for confidently wrong predictions.
3. **A linear model has a ceiling.** One perceptron draws one straight cut and cannot solve XOR. Hidden layers build a new representation in which the points become separable.

If you can explain these three ideas without the slides, you have the core of Lecture 1.

### Interview Answer Card: Lecture 1

ANSWER PATTERN: CONCLUSION → INTUITION → TRADE-OFF

Q1 Why cross-entropy, not MSE, for classification?

CE’s gradient (p − y)·x stays strong when the model is confidently wrong; MSE’s carries σ′(z) → 0 and stalls. CE is also the max-likelihood loss, and convex here.

Q2 GD vs SGD vs mini-batch?

Exact-but-slow vs cheap-but-noisy vs the practical middle. Mini-batch matches GPU parallelism; its noise even helps escape bad regions. Default everywhere.

Q3 Why can’t a perceptron solve XOR?

XOR is not linearly separable — opposite diagonal corners share a class; one hyperplane can’t group them (4 inequalities → contradiction). A hidden layer re-represents the inputs, making them separable.

Q4 Train / validation / test — what is each for?

Train fits parameters; validation selects hyperparameters and stopping; test is touched once for the honest final number. Tuning on test = leakage.
