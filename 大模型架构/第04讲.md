# 第 4 讲：卷积神经网络与经典视觉架构

图像具有二维邻域结构。卷积网络通过**局部连接、权重共享和位置平移时的对应变化**利用这种结构；残差连接进一步使深层网络容易训练。本讲先学会计算卷积的尺寸、参数和感受野，再理解 LeNet 至 ResNet 的发展，最后比较卷积与注意力的取舍。

## 1. 卷积如何处理图像

### 为什么不能只把图像展平

MNIST 图像大小为 $28\times28\times1$，CIFAR-10 为 $32\times32\times3$，常见 ImageNet 输入为 $224\times224\times3$。PyTorch 通常按 $N\times C\times H\times W$ 保存一批图像。展平后，模型本身不知道相邻像素更可能组成边缘和纹理。

将一张 $224\times224\times3$ 图像直接连接到 1000 个隐藏单元，需要 $150{,}528{,}000$ 个权重。展平还让相同边缘在不同位置分别学习，物体稍微平移就可能引起明显变化。卷积层让一个小滤波器在整张图上重复使用：既减少参数，又保留空间关系。

卷积采用三项主要假设：

- **局部性**：每个输出先观察一个邻域。
- **权重共享**：同一个特征检测器用于不同位置。
- **平移等变性**：输入平移时，特征图相应平移。

例如单个 $3\times3\times3$ 滤波器只有 27 个权重，另加一个偏置；其参数量不随图像高宽增长。图：同一滤波器逐位置扫描图像，产生一张特征图；边缘移动时，特征图中的响应位置也随之移动。

### 滑动、相乘、求和

对单通道输入与大小为 $k\times k$ 的核，深度学习中常称作“卷积”的运算通常按互相关实现：

$$
y[i,j]=\sum_{a=0}^{k-1}\sum_{b=0}^{k-1}x[i+a,j+b]K[a,b].
$$

在没有填充且步长为 1 时，$5\times5$ 输入与 $3\times3$ 核得到 $3\times3$ 输出。翻转核与不翻转核的严格数学定义不同，但核的值由训练学习，通常不影响模型能否学到相应模式。核可检测垂直边缘、水平边缘、模糊等特征；CNN 通过反向传播自行学习滤波器系数。

真实卷积层的每个滤波器跨越**所有输入通道**，一个滤波器产生一个输出通道。若有 $C_{\rm out}$ 个大小为 $k\times k\times C_{\rm in}$ 的滤波器，则含偏置的参数量为

$$
(k^2C_{\rm in}+1)C_{\rm out}.
$$

例如 $3\times3$、$64\to128$ 通道共有 $(9\cdot64+1)\cdot128=73{,}856$ 个参数。卷积层参数数目与输入高宽无关，但运算量随输出特征图面积增长。

### 填充、步长与输出尺寸

对每个空间轴，输入长度为 $n$、核大小 $k$、两侧填充 $p$、步长 $s$ 时，输出长度为

$$
n_{\rm out}=\left\lfloor\frac{n+2p-k}{s}\right\rfloor+1.
$$

| 输入 $n$ | 核 $k$ | 填充 $p$ | 步长 $s$ | 输出 |
| ---: | ---: | ---: | ---: | ---: |
| 32 | 3 | 1 | 1 | 32 |
| 32 | 3 | 1 | 2 | 16 |
| 224 | 11 | 2 | 4 | 55 |
| 7 | 7 | 0 | 1 | 1 |
| 55 | 3 | 0 | 2 | 27 |

奇数核取 $p=(k-1)/2$ 且步长为 1，通常可维持尺寸；步长为 2 常使长宽大致减半。余下不足一个窗口的边缘位置会被舍去。池化层也可用同一尺寸公式。

最大池化保留区域中最强响应，平均池化对区域求平均；二者都没有可训练参数。全局平均池化（GAP）把 $H\times W\times C$ 压缩成 $C$ 维向量，可用小型分类头替代巨大的全连接层。池化降低空间分辨率、增大后续单元的感受野，并提供一定程度的小平移容忍性。

**等变不等于不变**：卷积特征图通常随输入平移而平移；GAP 等汇总操作能进一步形成位置不变的表示。图像分类往往希望对小位移不敏感；定位和分割任务则需要保留“特征在哪里”的信息。

### 感受野、参数与运算量

感受野表示一个输出位置能够接触的原图范围。令初始感受野 $r_0=1$、相邻输出对应输入的间隔 $j_0=1$，逐层按

$$
r_\ell=r_{\ell-1}+(k_\ell-1)j_{\ell-1},
\qquad
j_\ell=j_{\ell-1}s_\ell
$$

更新。连续三层步长为 1 的 $3\times3$ 卷积，其感受野依次为 3、5、7；三层在通道数相同时需要约 $27C^2$ 个核权重，而单个 $7\times7$ 层需要 $49C^2$，且前三者增加了非线性。对“$3\times3,s1$ → $3\times3,s2$ → $3\times3,s1$ → $2\times2,s2$ 池化 → $3\times3,s1$”，感受野依次为 3、5、9、11、19。

卷积层的大致乘加次数为 $H'W'k^2C_{\rm in}C_{\rm out}$。缩小特征图可以节省空间运算；后期宽通道层则可能有更多参数。统计模型时应分别报告**参数量**和**乘加次数（MACs）**，不能只看一个数。

## 2. 从 LeNet 到 ResNet

### 经典架构怎样演进

| 架构 | 主要结构与贡献 |
| --- | --- |
| LeNet-5（1998） | 卷积、池化、全连接交替，用反向传播识别手写字符；约 6.2 万参数 |
| AlexNet（2012） | 扩大数据与 GPU 计算，结合 ReLU、Dropout、数据增强；约 6110 万参数 |
| VGG（2014） | 反复堆叠 $3\times3$ 卷积，结构统一，层数更深；约 1.384 亿参数 |
| GoogLeNet（2014） | Inception 并联不同尺度分支，用 $1\times1$ 瓶颈控制成本，采用 GAP；约 660 万参数 |
| ResNet（2015） | 通过残差连接稳定训练很深的网络；152 层版本约 6020 万参数 |

LeNet-5 的典型流程为 $32\times32\times1$ 输入、$5\times5$ 卷积、池化、第二次卷积与池化，再接全连接层。AlexNet 延续基本蓝图，但使用更大的 ImageNet 数据、GPU、ReLU 与正则化，使图像识别进入深度学习阶段。VGG 强调小核堆叠：两个 $3\times3$ 层覆盖一个 $5\times5$ 感受野，通常更省参数且多一次非线性；其大型全连接层却占了多数参数。

GoogLeNet 的 Inception 模块并联不同核尺寸，再沿通道拼接。先用 $1\times1$ 卷积把 192 通道压至 16，再做 $5\times5$ 到 32 通道，核权重从直接卷积的 $153{,}600$ 降至 $15{,}872$，约少 9.7 倍。早期层往往学习颜色与边缘，中间层组合纹理和部件，后期层组合更完整的物体特征；具体滤波器外观会受数据规模和训练时长影响。

### 深层普通网络的“退化”问题

更深的普通网络理论上至少可以模拟浅层网络：把新增层设成恒等映射即可。然而实验里，56 层普通网络可能比 20 层普通网络有**更高的训练损失**。这是优化上的退化问题，不能简单称作过拟合，因为训练集本身也变差。梯度在深层连续相乘，训练可能难以找到那些“什么也不做”的层。

ResNet 将块改写为

$$
y=x+F(x),
$$

让分支学习目标映射相对输入的**变化量**。若新层暂时不需要改动，令 $F(x)=0$ 就得到恒等映射。反向传播时

$$
\frac{\partial L}{\partial x}
=\frac{\partial L}{\partial y}
\left(1+\frac{\partial F}{\partial x}\right),
$$

其中恒等路径提供一条直接传递梯度的通道。跳跃连接本身在输入输出形状一致时不增加参数；尺寸或通道变化时，通常用步长合适的 $1\times1$ 投影匹配形状。

ResNet-18/34 常用两个 $3\times3$ 卷积的基础块；ResNet-50/101/152 常用 $1\times1$ 压缩、$3\times3$ 处理、$1\times1$ 扩张的瓶颈块。残差相加的思想也出现在 Transformer 等模型中：每层在已有表示上写入改变量。

~~~python
import torch.nn as nn
import torch.nn.functional as F

class Block(nn.Module):
    def __init__(self, ci, co, stride=1):
        super().__init__()
        self.f = nn.Sequential(
            nn.Conv2d(ci, co, 3, stride, 1, bias=False),
            nn.BatchNorm2d(co),
            nn.ReLU(),
            nn.Conv2d(co, co, 3, 1, 1, bias=False),
            nn.BatchNorm2d(co),
        )
        self.skip = nn.Identity()
        if stride != 1 or ci != co:
            self.skip = nn.Sequential(
                nn.Conv2d(ci, co, 1, stride, bias=False),
                nn.BatchNorm2d(co),
            )

    def forward(self, x):
        return F.relu(self.f(x) + self.skip(x))
~~~

## 3. 效率与归纳偏置

### $1\times1$ 卷积的用途

$1\times1$ 卷积在每个位置对通道向量做一次线性变换，不直接混合邻近像素；参数量为 $C_{\rm in}C_{\rm out}$。它可以减少或增加通道、在深度卷积后混合通道、配合非线性增加表达力，也可用于残差捷径的形状匹配。Transformer 的逐 token 前馈子层可从“每个位置分别变换通道”的角度理解。

### 深度可分离卷积

标准 $k\times k$ 卷积同时做空间处理和通道混合。深度可分离卷积先为每个输入通道单独做 $k\times k$ 空间卷积，再用 $1\times1$ 卷积混合通道：

$$
\text{标准核权重}=k^2C_{\rm in}C_{\rm out},\qquad
\text{可分离核权重}=k^2C_{\rm in}+C_{\rm in}C_{\rm out}.
$$

二者的比值为 $1/C_{\rm out}+1/k^2$。对 $3\times3$、$64\to128$ 通道，权重从 $73{,}728$ 降到 $576+8{,}192=8{,}768$，约少 8.4 倍。MobileNet 利用这一思想减少移动设备的开销，但理论 FLOPs 下降不必然等于实际延迟同比例下降，硬件访存也很重要。

现代 CNN 往往按“输入干路 → 多个阶段 → GAP → 小分类头”组织。阶段开始时用步长 2 缩小长宽并提高通道数，块内使用卷积、归一化和激活，再以残差连接稳定训练。小图像不必照搬大图像模型的 $7\times7$ 输入核。训练时可结合裁剪、合理的翻转、动量 SGD 或 AdamW、学习率调度，并比较消融实验；所有结论应与实际训练日志一致。

### 卷积与注意力各自假设什么

卷积把局部性、各位置共享同一滤波器和静态权重写进结构中，因此在数据较少时通常更有效率，但远距离位置需要经多层才能交互。自注意力根据输入内容计算位置间关系，能直接建立较远依赖，代价通常随位置数的平方增长。

视觉 Transformer 可把图像划分为 patch，再把 patch 当作 token。较少的人工结构假设通常意味着需要更多预训练数据；另一方面，经过改进训练方案的现代 CNN 也保持竞争力。选择模型要结合数据量、分辨率、算力、延迟和任务目标，而不是仅凭参数量判断。

## 本讲回顾

1. 卷积通过局部性和权重共享高效处理图像。输出尺寸、参数量和感受野分别由核、步长、填充、通道数及层间步长决定。
2. 池化与 GAP 汇总空间特征；卷积通常保留平移等变性，分类头进一步追求一定程度的不变性。
3. 残差块 $y=x+F(x)$ 让网络容易保持恒等映射，也给梯度提供直接通路，从而减轻深层普通网络的退化问题。
4. $1\times1$ 卷积和深度可分离卷积降低成本；卷积的归纳偏置与注意力的内容自适应关系各有适用场景。
