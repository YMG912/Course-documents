# Lecture 4: Convolutional Neural Networks

## Why Convolutional Networks?

An image is a grid with local structure. Flattening a $224\times224\times3$ image and connecting it to $1{,}000$ hidden units requires $150{,}528{,}000$ weights in the first dense layer. A convolutional filter reuses the same small set of weights at many image locations, reducing parameters and preserving local neighborhoods.

| Idea | Effect |
| --- | --- |
| Local receptive fields | A unit responds to a small nearby region. |
| Weight sharing | The same pattern detector is applied across positions. |
| Padding and stride | Control output size and how densely the filter is applied. |
| Pooling | Reduces spatial size and summarizes nearby responses. |
| Residual connection | Lets a deep block learn a change to its input, improving optimization. |

图： comparing a plain deep network with a residual network illustrates the degradation problem: adding layers can increase training error even when the deeper model could represent the shallower one. Skip connections make the identity path available, so the extra layers need only learn a useful residual.

## The Residual Idea: Learn the Change, Not the Whole
x conv 3×3 · BN · ReLU conv 3×3 · BN + ReLU y
identity x — the shortcut
F(x) — the residual branch
y = F(x) + x ⇔ F(x) = H(x) − x
the block learns the residual (the change); the shortcut carries the input Plain: the two layers must learn H(x) — including
“do nothing”, which is hard to express through two
nonlinear layers.
Residual: the two layers learn F = H − x; “do
nothing” is F = 0 — weights → 0, which is easy
(weight decay even pushes there).
学变化量 — zero new parameters, one addition. Identity becomes the default; depth becomes safe.

## Interview Answer Card: Lecture 4 (1/2)
ANSWER PATTERN: CONCLUSION → INTUITION → TRADE -OFF
Q1 Input n, kernel k, padding p, stride s: output size and parameter count?
out = ⌊(n + 2p − k)/s⌋ + 1 per axis; params = (k²·C_in + 1)·C_out, independent of n. Example: 32, k3, p1, s2 → 16;
3×3 conv, 64 → 128: 73,856.
Q2 How do you compute a receptive field?
r ← r + (k − 1)·j, j ← j·s, from r = j = 1. Stacked 3×3: 3, 5, 7; after a stride-2 layer every kernel cell covers twice as much input. Hour 1’s five-layer stack → 19.
Q3 What does ResNet fix, and why does it work?
Degradation: a deeper plain net has higher training loss. y = x + F(x) makes identity the default (F = 0 is easy) and gives the gradient a ‘1’ path: ∂L/∂x = ∂L/∂y · (1 + ∂F/∂x).
Q4 What is a 1×1 convolution for?
A per-pixel FC layer: reduce / expand channels (bottleneck — 9.7× cheaper in GoogLeNet), mix channels after a depthwise conv, add nonlinearity, projection shortcuts.

## Interview Answer Card: Lecture 4 (2/2)
ANSWER PATTERN: CONCLUSION → INTUITION → TRADE -OFF
Q5 What does pooling do? Max vs. average? Why GAP?
Downsample, small-shift invariance, larger receptive field, zero params. Max keeps the strongest feature, average smooths; GAP: H×W×C → C, no FC stack (VGG’s fc6: 102.8M params).
Q6 Why stacks of 3×3 instead of one large kernel?
Three 3×3 = one 7×7 receptive field with 27C² vs 49C² params (45% fewer) and three nonlinearities instead of one; two 3×3 = one 5×5 (18C² vs 25C²).
Q7 Depthwise separable convolution — how much does it save?
k×k per channel (groups = C_in) + 1×1 across channels: cost ratio 1/C_out + 1/k² ≈ 1/9 for 3×3. 64 → 128: 73,728 → 576 + 8,192 = 8,768 weights, 8.4× fewer .
Q8 CNN vs. ViT: inductive bias?
CNN assumes locality, sharing, static weights → data-efficient, equivariant. ViT assumes little, learns global relations from content → needs large pre-training; wins at scale, hybrids in practice.
