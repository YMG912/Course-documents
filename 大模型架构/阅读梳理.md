# 大模型架构：从一个判断器到可训练的深层网络

先抓住一条主线：**用数据定义任务，用损失衡量错误，用梯度改进参数；当简单模型表达不了问题时，增加网络层数，并让训练过程保持稳定。**

## 1. 机器究竟在学什么

- 监督学习是从带答案的样本中学习映射。先明确输入、期望输出和评价方式，再选模型与损失函数。训练集用于调整参数，验证集用于选方案，测试集用于最后评估；真正重要的是**对未见数据的表现**。
- 人工智能包含机器学习，深度学习是机器学习的一类方法，基础模型可通过大规模预训练适配多种任务。无监督学习寻找未标注数据的结构，自监督学习则从数据自身构造预测目标。
- 回归预测连续数值，常用均方误差；分类预测类别，常用概率和交叉熵。比如预测房价要关心价格误差，判断邮件是否为垃圾邮件要关心类别概率。损失必须与任务相符。
- 线性回归用加权求和预测数值；逻辑回归用 Sigmoid 将线性分数转成二元概率。前者的均方误差与高斯噪声假设相关，后者的交叉熵与伯努利概率模型相关；用概率建模能解释为什么选择不同损失。
- 梯度告诉我们“参数改动一点，损失会怎样变化”。梯度下降沿降低损失的方向更新参数；学习率过小会慢，过大会震荡甚至发散。小批量训练在计算成本和更新噪声之间折中。
- 简单线性问题有时可直接求最优解；参数多或模型复杂时通常迭代优化。全批量更新稳定但成本高，单样本更新噪声大，小批量是常见折中。

**关键结论：** 模型在训练数据上表现好，只说明它学会了这些样本；是否学到可迁移的规律，要靠独立数据检验。

## 2. 单层模型为何需要变成多层网络

- 线性回归和感知机都以一条直线（高维时为超平面）划分或拟合数据。感知机可处理线性可分的情况，却不能只用一条直线解决异或（XOR）：两个输入不同才输出真。
- 感知机把分数直接变成硬判断，只在分类错误时按方向调整权重；逻辑回归输出概率并通过交叉熵学习。对于线性分类，交叉熵的梯度通常比“Sigmoid 加均方误差”在饱和时更有用。
- 多层感知机（MLP）在矩阵变换之间加入**非线性激活**，让隐藏层先重组特征，再由输出层做判断。若没有激活函数，多层线性变换仍等价于一次线性变换，增加层数不会扩大这类表达能力。
- 足够宽的非线性隐藏层可以近似很多函数，但“能表示”不意味着“容易学到”；深度能复用中间特征，往往比一味增宽更有效。
- ReLU 计算简单，正值区域有稳定梯度，但某些神经元可能长期停在零输出区域。Sigmoid、Tanh 输出有界，却可能在饱和区出现很小的梯度。输出层则按任务选择：二分类常用 Sigmoid，多分类常用 Softmax，数值回归通常直接输出实数。
- Leaky ReLU 等变体给负值区域保留小斜率，可缓解“死亡 ReLU”。激活函数、输出层与损失函数要成套匹配。

**关键结论：** 深度的价值在于逐层组合简单特征，而非机械地堆叠矩阵。

## 3. 网络如何知道每一层该改什么

- 前向传播依次计算各层输出与损失；反向传播从损失出发，用链式法则把误差信号传回每一层。一次反向计算即可得到大量参数的梯度。
- 对 Softmax 加交叉熵的多分类问题，输出分数的梯度可简写为“预测概率减目标概率”，即 $p-y$。它直接指出每一类的预测偏差。
- 自动求导负责执行反向传播，但仍要核对张量形状、损失实现、梯度数值和参数是否真的更新。若损失不降，可先尝试在一小批样本上过拟合，以定位实现或配置问题。
- 计算图把复杂模型拆成局部运算；反向传播复用前向中间结果，效率高但需保存激活，占用内存。数值梯度检查可验证手写反向传播；Softmax 与交叉熵合并计算可减少数值溢出。

**例子：** 手写数字识别可把图像展开为向量，经“线性层 → ReLU → 线性层 → 类别概率”得到预测；训练时依据正确数字的标签将误差逐层传回去。

## 4. 深层网络能训练起来，还要能泛化

- 初始化应让信号和梯度在层间保持合适尺度。ReLU 网络常用 He 初始化；过大或过小的初始权重会使激活与梯度爆炸或消失。
- SGD 用当前梯度更新；动量能平滑方向，Adam 用梯度的一、二阶统计量调节每个参数的步长，AdamW 将权重衰减与自适应更新分开。学习率及其调度通常比微小的优化器差别更值得优先检查。
- AdaGrad 给不同参数累计不同步长，但步长可能持续缩小；RMSProp 用移动平均避免历史梯度无限累积。训练初期的预热和后续学习率衰减可改善不稳定更新。
- 训练损失和验证损失都高，通常是欠拟合；训练继续变好而验证变差，通常是过拟合。可结合数据增强、权重衰减、Dropout、提前停止来改善泛化。归一化、残差连接和梯度裁剪有助于稳定深层训练，但各有适用条件。
- BatchNorm 使用批次统计量，训练与推理的行为不同，小批次时可能不稳定；LayerNorm 沿单个样本的特征归一化。Dropout 只在训练时随机屏蔽部分单元；梯度裁剪主要控制异常大的梯度。
- 调参先检查数据和实现，再定合理基线，随后调整学习率、模型容量和正则强度；每次比较使用同一验证标准，并保留最后未参与选择的测试集。

**关键结论：** 优化方法负责把训练误差降下来；泛化方法决定这种改进是否能用于新样本。

## 5. 图像为何常用卷积网络

- 图像是有空间邻近关系的网格。把它直接展开会丢失这种结构，还会让全连接层使用大量参数。卷积核只看局部区域，并在不同位置共享权重，因此擅长寻找边缘、纹理、局部部件等模式。
- 一个卷积核跨越输入的全部通道，产生一张特征图；多个卷积核产生多个输出通道。步幅和池化缩小特征图，填充控制边界与输出尺寸；由核大小、步幅、填充可算每层输出大小。
- 多层卷积扩大感受野，让后层逐渐组合出更复杂的对象特征。卷积的平移等变性意味着目标移动时特征响应也随之移动；池化可增加局部位置容忍度，却不保证所有平移下输出完全不变。
- LeNet 建立了“卷积提特征、后续层做判断”的流程；AlexNet 借助更大数据与计算推动深层视觉模型；VGG 用重复小卷积核加深网络；GoogLeNet 以并行分支和 $1\times1$ 卷积控制成本。
- 更深的普通网络可能出现训练退化。ResNet 用 $y=x+F(x)$ 的跳连让信息和梯度更容易跨层传递；深度可分离卷积把空间过滤与通道混合分开，以较低成本运行。选架构时同时看参数量、实际运算量和准确性。
- 卷积预设局部性与权重共享，适合图像；注意力可以按内容学习远处位置之间的关系。两者各有计算代价与结构偏好，不能仅凭模型规模判断哪种更适合任务。

**贯通结论：** 架构设计始终在回答三个问题：数据有什么结构、模型需要怎样的表达能力、这样的模型能否稳定且高效地训练。
