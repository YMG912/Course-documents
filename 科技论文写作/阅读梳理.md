# 科技论文写作：把研究问题讲清楚、证据摆准确

一篇好论文应形成一条能被检查的论证链：**问题值得研究 → 现有方法留下空缺 → 方法能检验问题 → 结果支持有限而明确的结论。** 两份课程内容分别帮助读者建立这条链，并守住投稿与工具使用的边界。

## 1. 选一个能回答的问题

- 选题要有价值、可回答、可完成。题目过大时，先缩小研究对象、条件和评价标准。
- 在动手前写清：研究对象是什么，要解决什么困难，已有方法哪里不足，怎样判断新方法是否有效。
- 结论的范围不能超过证据。某方法在一个数据集上超过一个基线，只能支持该实验条件下的比较，不能推出它在所有情形都更好。
- 科学性要求论点有可靠事实与可复核的方法；原创性要求有新发现或新进展；逻辑性要求前提、证据和结论衔接；有效性要求研究能按规范被同行检查和使用。

**例子：** 与其写“新算法改善预测”，不如明确“在某类数据、统一指标和相同训练条件下，比较新算法与哪些基线”。

## 2. 选对论文类型与思维方法

- 学术性论文重在提出或检验新知识，技术性论文重在解决具体工程或应用问题；两者都需要清楚说明贡献和使用条件。
- 论证型解释命题或模型是否成立，报告型如实记录研究过程和结果，发现或发明型说明新现象或新方法，设计或计算型说明方案及其性能，综述型比较已有成果与趋势。类型决定文章应呈现什么证据。
- 分析把复杂问题拆开，归纳从观察中找共同点，综合把部分认识连成整体，演绎从原理推出具体结论。写作时常交替使用，不能把原始材料直接堆成“结论”。

**例子：** 研究一种材料时，发现新规律、改进可用配方、比较现有检测方法，分别需要不同的论证重点。

## 3. 用文献和实验搭起论证

- 引言依次交代背景、研究空缺、本文目标、方法与贡献。文献综述按问题或方法比较已有工作，指出假设、适用范围和局限，不只是列出文章摘要。
- 对比实验要交代数据、指标、基线和条件；误差分析与失败情形同样重要。读者需要知道结果为什么可信，也需要知道它在哪些条件下可能不成立。
- 借鉴的观点、数据和图表须准确标注；研究记录应可核查。原创贡献和已有工作要明确区分。
- 综述可以客观汇集资料，也可以在比较证据后提出评述；无论哪一种，都要让读者明白各方法何时适用、各自还有什么不足。

## 4. 让文字与图表为结论服务

- 标题、摘要、正文和结论应讲同一个研究问题。摘要概括问题、方法、主要结果和结论；结论回答开头的问题，并说明适用范围。
- 一段只讲一个要点，先给结论，再给支撑。术语、符号、单位与缩写前后一致；图表要说明展示了什么、支持什么结论。
- 避免“效果很好”一类不可核查的评价，改用具体指标与比较条件。完稿后检查断句、错字、编号与引文。

## 5. 正确使用人工智能工具

人工智能工具可帮助解释概念、整理提纲、检查语句和比较表达方式。提问时说清**任务、背景、约束和输出形式**，检查第一次回答后再修订；上下文、目标、风格、语气、受众和回应形式可作为提示词清单。

**事实、计算、引用与最终结论仍由作者核实并负责。** 模型可能编造文献或混淆出处，生成的文字不能代替实验或独立论证。未公开材料也要注意隐私与版权，使用与披露方式应符合当前适用的投稿要求。

## 6. 从写完到投稿仍要守住规范

- 同一稿件的并行投稿、预印本公开、版权安排与 AI 使用声明，均应核对目标渠道的现行规则。预印本可以较早公开成果，但不等于已通过同行评审。
- 保存研究记录、数据版本和投稿往来；逐条核对引文是否真实、是否支持论点。不能伪造实验、抄袭、隐瞒应披露的工具使用，或把自动检测结果当作学术诚信的唯一判断。

**贯通结论：** 论文的核心不是把研究写得复杂，而是让每个主张都有相称的证据，让读者清楚知道“解决了什么、怎么验证、还有什么局限”，并能信任内容确由作者核查和负责。
