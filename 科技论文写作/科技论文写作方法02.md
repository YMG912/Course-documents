# 科技论文写作方法 02：论文类型、论证与人工智能工具

科技论文把可核查的研究过程与结论交给读者。写作时既要让问题、方法和证据连贯，也要对数据、引文及人工智能工具的使用负责。

## 一、把人工智能当作学习与写作助手

人工智能工具适合用来解释概念、比较措辞、整理提纲、检查表达，或根据反馈修改草稿。它能提高处理文字的效率，但不能替代研究者判断事实、解释结果和承担责任。模型能力会随任务而变化，不能因为某项基准测试表现好，就推断其所有回答都可靠。

图：不同模型在数学、代码和科学问答任务中的表现各异；比较模型时应按具体任务与评价指标判断。

有效提问可逐步补足四类信息：

1. **任务：** 需要做什么，例如检查摘要是否交代问题、方法、结果与局限。
2. **背景：** 研究对象、读者和已有材料是什么。
3. **约束：** 长度、术语、必须保留的结论，以及不能新增事实或引用的要求。
4. **反馈：** 核对第一次输出，指出不准确之处，再要求修订。

CO-STAR 框架把提示词拆成**上下文、目标、风格、语气、受众、回应形式**。这些项目是帮助澄清需求的清单，不必每次机械填满。比如：“面向跨学科读者，将这段摘要改为 150 字；保留原有实验结果，解释缩写，不补充未经核实的数据。”

图：CO-STAR 将提问要求拆成六个维度，帮助写作者同时说明“做什么、给谁看、怎样回答”。

图：提问从笼统任务逐步加入背景、细节和输出要求，再根据核查结果迭代；要求越清楚，回答越容易检验。

使用工具时应避免上传未经许可的私人或未公开材料，并注意安全、隐私、系统安全、版权和学术伦理。写作者要保持独立思考，不能把生成文本直接当作证据。

图：人工智能带来便利，也可能扩大隐私泄露、内容失真与版权风险；人的判断和核查仍是关键环节。

## 二、投稿与预发表的基本边界

- **一稿多投：** 同一稿件同时投向多个要求独家审稿的渠道，可能违反投稿规则并引发版权纠纷。投稿前核对目标期刊或会议的具体政策；撤稿、转投和已发表版本也须按规则处理。
- **预发表：** 预印本可以较早公开研究成果、获得反馈并留下公开记录，但通常尚未经过正式同行评审。能否在预发表后投稿、是否需要声明，以及版权如何安排，都以目标渠道的现行规则为准。
- **研究材料保护：** 保存带日期的研究记录、数据版本、实验代码与投稿往来，有助于说明成果的形成过程；公开前也要确认合作者意见和保密义务。
- **引用与署名：** 他人的文字、数据、图表和方法必须准确标注。未经核实的内容不能因出现在预印本或模型回答中就视为可靠；也不能把他人成果冒作自己的研究。

**关键结论：** 公开、投稿和引用都是研究传播的一部分，诚信要求贯穿写作前后。

## 三、科技论文如何形成论证

科研写作常交替使用四种思维方法：**分析**把复杂问题拆开考察；**归纳**从多个观察中概括规律；**综合**把局部认识重新连成整体；**演绎**从已知原理推出具体情形。它们服务于同一条论证链：提出问题和假设，获得材料，解释证据，得出有范围的结论。

科技论文通常具有四项核心要求：

| 要求 | 关键结论 |
| --- | --- |
| 科学性 | 概念和判断应符合客观事实，论据来自可靠数据或观察；方法与条件要写清，使他人能够检查或复核。 |
| 原创性 | 应有新的发现、方法、数据、解释或应用进展，不能只复述、模仿已有工作。 |
| 逻辑性 | 前提、证据和结论要衔接，计算和符号要正确，图表与文字要共同支持论点。 |
| 有效性 | 内容应按适当学术规范传播，便于同行评议、使用和进一步验证；发表本身不等于结论永远正确。 |

不能虚构实验、伪造结果，或用一堆原始数据代替分析。可复核的研究记录与适度说明局限，往往比夸大的结论更有说服力。

## 四、先确定写的是哪一类论文

- **学术性论文**侧重研究问题、新观点、新方法或新数据；**技术性论文**侧重用理论解决工艺、设备、材料、设计等具体问题，并说明可用性与条件。
- **论证型**围绕命题、原理或模型建立和检验论证，要讲清适用条件；**科技报告型**如实记录研究进展、方法和正反结果，供后续工作使用。
- **发现或发明型**说明新现象、新规律，或新装置、材料、工艺、方法的性能、原理与使用条件；**设计或计算型**解释方案、算法或模拟如何解决问题，并检查精度、稳定性等指标。
- **综述型**整理一个领域的研究进展。客观型综述重在归集和说明，评述型综述还要比较证据、指出不足与发展方向；它不是文献标题的堆叠。方法综述尤其要讲清方法何时适用、怎样规范使用。

**例子：** 同样研究一种材料，提出新的测量规律偏向学术论证，改进可量产的配方偏向技术论文，比较多个检测方法的适用范围则偏向综述。

## 五、人工智能使用后的核查责任

人工智能可能留下模板化语句、捏造不存在的文献，或把真实题目与错误作者、期刊、年份拼接。逐条核对引文是否真实、是否支持文中的说法；逐项复查数字、公式、图表和推理，不应只做语言润色。即使稿件通过同行评审，作者仍须为内容负责。

人工智能使用与披露要求会随学科、期刊和机构变化。写作时应查阅当前适用规则，保存必要的使用记录，按要求说明工具承担的工作。自动检测结果不能取代对事实、证据和研究过程的审查。

图：不同渠道的规范与检测要求各有差异；应先查当前规则，再留痕并按要求披露，不能套用别处的阈值或流程。

图：从生成草稿到提交论文之间，应经过“核实事实与引用 → 对照原始记录 → 检查原创性与披露要求 → 人工定稿”的关口。

**贯通结论：** 人工智能能帮助表达，可信的科技论文仍依赖清楚的问题、可复核的研究和由作者负责的论证。
