# 机器学习原理：从问题到可检验的预测

学习这门课可沿着“**定义问题 → 表示数据 → 衡量错误 → 优化模型 → 检查泛化**”前进。数学工具服务于这条流程，不必孤立记公式。

## 1. 先把任务说清楚

- 人工智能是更广的目标；机器学习从数据中学习规律，深度学习用多层神经网络自动构建特征表示。算法、数据与算力共同影响实际效果。
- 分类回答“属于哪类”，回归回答“数值是多少”。带标签数据对应监督学习；无标签数据可用于聚类或降维；自监督学习从数据自身构造训练信号；强化学习通过行动后的奖励改进策略。
- 半监督学习把少量有标签样本与大量无标签样本结合；迁移学习把一个任务学到的表示用于另一个任务。选择学习范式，取决于标签、反馈和任务差异。
- 一个可评估的任务要说明输入、目标、数据范围和评价指标。比如天气预测不能只报一个最可能结果，若输出概率，还应检查概率是否可信。
- 数据要分成训练、验证和测试用途；实际数据的噪声、标注成本、分布变化及计算限制，会使训练成绩与实际效果出现差距。评价还可能包括可解释性、运行效率和可靠性。

**关键结论：** 先定义成功标准，再谈模型。训练误差低不等于在真实场景可靠。

## 2. 用向量和矩阵表示数据与模型

- 一个样本可写为特征向量；多个样本排成矩阵 $X$。线性模型的批量预测是 $\hat y=Xw$：每行是一个样本，每列是一个特征，$w$ 表示各特征的权重。
- 标量、向量、矩阵和张量分别有不同数量的索引轴；图像批次还要区分批次、高度、宽度与通道。向量维数是坐标数量，张量阶数是轴的数量。
- 内积衡量方向关系，也可用于计算相似度；范数衡量向量或矩阵的大小；矩阵乘法表示连续的线性变换，**顺序通常不能交换**。学习时先核对各维度能否相乘，比死记展开式更有用。
- 线性无关说明特征方向没有重复；矩阵的秩表示独立方向数。向量空间和子空间要对加法、数乘封闭；仿射集合若不含零向量，就不是子空间。
- 内积与投影说明一个向量在另一方向上有多少分量；三维叉积给出垂直方向，外积生成矩阵。单位矩阵保持不变，对角矩阵按坐标缩放；迹是对角线元素之和，行列式为零意味着方阵不可逆。
- 正交变换保留长度与夹角；Gram 矩阵汇集内积。$L_1$、$L_2$ 和 Frobenius 范数可分别衡量向量或矩阵的大小与误差。
- 特征值描述方阵在某些特殊方向上的缩放。奇异值分解（SVD）把任意矩阵拆成“旋转、按方向缩放、再旋转”；保留主要奇异方向可做压缩和降维，但会舍弃部分信息。

**例子：** 将许多图像排成数据矩阵后，保留最大的几个奇异方向，可以用较少数字描述主要变化，但小细节可能丢失。

## 3. 用微积分决定怎样改参数

- 损失函数把预测错误压缩成可比较的数值。梯度给出各参数附近的下降方向；链式法则把输出处的误差逐层传回输入和参数，是反向传播的基础。
- Jacobian 描述向量函数对输入小变化的响应；Hessian 描述损失的局部曲率。初学时只需把握：一阶信息告诉“往哪走”，二阶信息补充“弯得多厉害”。
- 对称矩阵的特征分解有正交特征方向；Hessian 在驻点附近的正负曲率有助于区分局部极小与鞍点，但不能代替对全局结果的检验。
- 激活函数可能出现梯度饱和：例如 Sigmoid 输入绝对值很大时，导数接近零，深层训练中的早期参数就可能更新缓慢。

## 4. 把模型输出解释为概率

- 多分类模型给每类一个分数，Softmax 把分数变成总和为 1 的概率；分数越高，相应概率通常越高。交叉熵惩罚模型给正确类别很低概率的情况。二者结合时，输出分数的梯度为 $p-y$，便于稳定训练。
- 为避免指数溢出，计算 Softmax 时可先让所有分数减去同一个最大值；概率不变。Logit 把二元概率变回实数分数，Softplus 是平滑的正值变换。
- 熵表示分布的不确定性，条件熵表示已知另一变量后还剩多少不确定性，互信息表示观察另一变量后减少了多少。交叉熵表示用预测分布描述目标分布的代价；KL 散度衡量差异但不对称，JS 散度对称，Wasserstein 距离还考虑概率质量移动的距离。
- Bernoulli 分布适合单次二元结果，Binomial 分布记录多次二元试验的成功数；Categorical 和 Multinomial 分别对应单次和多次多类别结果。高斯分布描述连续数值及相关性，Laplace 分布的尾部较厚；经验分布直接由样本形成，高斯混合可表达多个聚集区域。
- 多元高斯里的 Mahalanobis 距离把不同方向的方差和相关性纳入距离计算。选择概率模型时要看数据如何产生、误差有什么特点。

**贯通结论：** 矩阵使模型能批量计算，梯度使模型能学习，概率使预测能表达不确定性；最终仍须用独立数据检验模型是否学到了可泛化的规律。
