# 机器学习原理：课程导论

## 人工智能与机器学习

人工智能研究如何构建能够感知、学习、推理和决策的系统。机器学习是实现人工智能的重要途径：算法从数据中发现规律，建立可用于预测或决策的模型，并通过经验改进性能。深度学习是机器学习中的一类方法，使用多层神经网络学习数据表示。

图：人工智能、机器学习、表示学习和深度学习之间呈包含与交叉关系。深度学习尤其强调由多层模型自动学习有用的特征表示。

机器学习结合概率统计、线性代数、优化和计算方法。它处理的通常不是能逐条写出规则的问题，而是要从样本中学习复杂的映射。例如，图像分类将像素映射为类别，语音识别将声音映射为文字，推荐系统根据行为预测用户可能感兴趣的内容。

## 人工智能的发展脉络

早期研究受到神经科学、控制论、计算理论和信息论的影响。1956 年的达特茅斯会议推动人工智能成为独立研究领域，研究者讨论了可编程计算机、语言、神经网络、抽象和自我改进等主题。

此后，人工智能经历了多轮发展和低谷。早期系统的能力与当时的乐观预期存在差距；专家系统取得过应用成果，但维护成本和适应能力限制了其普及。统计学习方法、数据规模、计算能力和算法的进步，后来推动了机器学习与深度学习的发展。反向传播、卷积网络、序列建模、注意力机制和预训练模型是其中的重要技术节点。

图：技术发展的关键条件包括算法、数据和算力。三者共同决定模型能学到什么，以及能否在实际任务中运行。

## 一个机器学习问题如何求解

1. **定义任务和输入输出。** 明确希望模型从哪些数据预测什么结果。例如，分类任务输出类别，回归任务输出数值。
2. **选择模型。** 使用带参数的函数 $f_\theta(x)$ 表示输入与输出之间的关系。
3. **定义损失。** 用训练样本衡量预测与目标之间的差异。
4. **优化参数。** 调整 $\theta$ 以减小训练损失。
5. **评估泛化。** 在训练时未见过的数据上检查性能，并关注错误类型、计算成本和实际使用条件。

图：数据经过模型得到预测；损失函数比较预测与目标，优化算法再根据损失调整模型参数。这一过程循环进行，直到达到所需的性能或训练停止条件。

### 典型应用

| 任务 | 输入 | 输出与主要评价角度 |
| --- | --- | --- |
| 数学和代码推理 | 题目或程序要求 | 解题过程与答案；关注正确率、测试通过率和推理成本。 |
| 文档理解 | 图像及文字指令 | 文字、表格或结构化字段；关注识别准确性与版式变化下的表现。 |
| 视频分割 | 视频及点击、框等提示 | 目标在各帧中的区域；关注区域重叠度、边界质量与交互次数。 |
| 语音翻译 | 语音或文本、目标语言 | 翻译后的文本或语音；关注翻译质量和噪声、口音下的稳定性。 |
| 内容推荐 | 按时间排列的交互记录 | 内容排序或后续交互预测；同时关注长期体验与反馈偏差。 |
| 分子结构预测 | 分子序列与化学信息 | 三维结构及置信度；预测结果仍需实验验证。 |
| 概率天气预报 | 近期天气状态 | 多种可能的未来天气情景；关注概率校准与极端事件表现。 |
| 机器人操作 | 图像、指令和机器人状态 | 连续动作；关注新环境中的任务完成率和运行安全。 |

## 为什么机器学习困难

现实数据通常维度高、噪声多，标注数据可能昂贵，训练和实际使用的数据分布也可能不同。视觉任务中的像素只是数字；要识别物体，模型还须从这些数字中学习形状、位置和语义关系。

一个完整的学习问题包含数据、算法和模型。数据需要划分为训练集、验证集和测试集；算法利用数据寻找规律；模型则应在拟合已有样本与适应新样本之间取得平衡。仅仅降低训练误差并不足够，过于复杂的模型可能记住训练数据而无法泛化。

常见评价指标包括预测准确性、可解释性、运行效率和任务相关的可靠性。指标应与实际用途一致：例如概率预报还需要检查校准程度，推荐系统还要注意长期体验，机器人系统还要考虑安全。

## 主要学习范式

| 范式 | 训练信号与典型任务 |
| --- | --- |
| 监督学习 | 使用带标签的样本，完成分类或回归。 |
| 无监督学习 | 从无标签数据中发现聚类、关联或低维结构。 |
| 自监督学习 | 从数据自身构造训练目标，学习可迁移的表示。 |
| 半监督学习 | 结合少量带标签样本和大量无标签样本。 |
| 强化学习 | 通过与环境交互和奖励信号学习行动策略。 |
| 迁移学习 | 将已有任务或领域学到的知识用于新任务。 |

深度学习使用高维、可组合的函数表示复杂关系。大规模数据和计算资源能帮助训练这类模型，但模型结构、训练目标与评估方法仍然决定它是否真正解决问题。
